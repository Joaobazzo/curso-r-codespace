# Comece aqui

Este é o ambiente do curso **Análise de Dados com R Aplicada ao Planejamento de Transportes**,
rodando inteiro no navegador. Você não precisa instalar R, RStudio, Rtools nem pacote nenhum:
tudo já está pronto, e é igual para todos os participantes.

## 1. Abra o RStudio

Na primeira vez, o ambiente leva alguns minutos para ficar pronto: ele instala os pacotes e
baixa os dados do Módulo 1. Acompanhe pelo terminal, aqui embaixo. Quando aparecer
`Ambiente pronto`:

1. Clique na aba **PORTAS** (*PORTS*), no painel inferior.
2. Na linha **RStudio (8787)**, clique no ícone de globo (*Abrir no navegador*).

O RStudio abre numa nova aba do navegador. Daqui em diante, o curso acontece lá.

> Se a aba do RStudio já abriu sozinha, pode pular este passo.

## 2. Abra o projeto

No RStudio, em `File > Open Project...`, escolha `curso-r-codespace.Rproj`.

## 3. Comece pelo Módulo 1

Os capítulos estão na pasta `modulo1/`, em ordem:

| Arquivo | Conteúdo |
|:--|:--|
| `01-ambiente.qmd` | O ambiente na nuvem, projetos, caminhos, pacotes, `renv` |
| `02-linguagem.qmd` | Objetos, vetores, fatores, matrizes, listas, `data.frame`, funções, iteração |

Abra o arquivo e rode cada bloco de código com o botão ▶ (canto superior direito do bloco)
ou com `Ctrl + Shift + Enter`. A saída aparece logo abaixo do bloco.

## Cuidados

- **Seu trabalho fica salvo** dentro do Codespace, mesmo depois de fechar o navegador.
  Para voltar, acesse <https://github.com/codespaces> e clique no seu Codespace.
- **Codespaces parados há 30 dias são apagados.** Baixe o que for importante (botão direito
  no arquivo, *Download*) ou envie para o seu GitHub (Módulo 5).
- **Feche quando terminar.** A cota gratuita do GitHub é contada em horas de uso. Em
  <https://github.com/codespaces>, use `...` > *Stop codespace*. Ele também para sozinho
  depois de 30 minutos sem uso.
- **A regra de ouro vale aqui também:** não suba para o Codespace nenhum dado que você não
  publicaria no site do Ministério.
